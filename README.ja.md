# CayenChat

[English README](README.md)

Rust と GPUI で作ったコンパクトなネイティブ IRC クライアントです。アプリ内でサーバーを設定し、接続してチャンネルに自動参加できます。接続設定は保存されますが、チャット履歴は保存されません。

## ライセンスと画像

CayenChat の独自ソースコードと `icon.png` は [GPL バージョン 3 のみ](LICENSE)で提供します。`crates/ui/src/input.rs` の GPUI 由来の入力部品は Apache-2.0 のままで、外部依存にはそれぞれのライセンスが適用されます。[サードパーティーの告知](THIRD_PARTY_NOTICES.md)を参照してください。GPUI の Apache-2.0 と GPLv2 は両立しないため、GPLv2 は使用していません。配布時にはこれらの告知を残してください。

## ビルドと起動

Cargo を含む Rust 1.88 以降が必要です（macOS では 1.95.0、Linux では 1.98.1 で確認済み）。GPUI が `let` チェーン構文を使っているため、それより古いコンパイラではビルドできません。Debian 標準の rustc（1.85）は古いので、backports か rustup を使ってください。コマンドはリポジトリのルートで実行します。Cargo はコミット済みのロックファイルを使用し、初回ビルドではキャッシュにない依存ライブラリをダウンロードします。

```sh
cargo build --locked -p cayenchat-ui
cargo run --locked -p cayenchat-ui
```

デバッグ版は `target/debug/cayenchat` です。最適化版は `cargo build --locked --release -p cayenchat-ui` でビルドでき、`target/release/cayenchat`（Windows では `cayenchat.exe`）に生成されます。

## IRC への接続

通常は起動時に設定ウィンドウが別に開きます。閉じても4ペインのチャットウィンドウは動作し続けます。再度開くには、macOS では **CayenChat → 接続設定…**（`Cmd+,`）、Windows/Linux では `Ctrl+,` を使います。**接続**タブでニックネームを入力し、**接続先**からサーバーを選んで **保存して接続** を押します。初期サーバーは TLS 無効・ポート `6667` の `irc.ircnet.ne.jp` です。`irc6.ircnet.ne.jp` も標準で登録されています。**＋ サーバーを追加…** で独自の接続先を保存でき、追加したサーバーは標準の候補より先に表示されます。ホスト名、ポート、TLS 証明書の検証設定、文字コードはサーバーごとの設定です。自動参加チャンネルは `#first,#second` のようにカンマ区切りで指定します。空欄にして、接続後に `/join #channel` で参加することもできます。

サーバーごとに **文字コード** から UTF-8（初期値）、ISO-2022-JP、Shift_JIS、EUC-JP を選べます。IRC ではチャンネル名を含めて文字コードが一律に定められていません。CayenChat は日本語のチャンネル名も含む IRC 行全体を、選択した文字コードで符号化・復号します。チャンネルへの参加や送信では同じ文字コードを使う必要があるため、参加前にネットワークで使われる文字コードを選んでください。ISO-2022-JP のチャンネル名では、日本語文字のバイト列にカンマやコロンのバイトが含まれることがあります（例: `#がが`）。ネットワーク上でその名前が機能するかどうかはサーバー側にも依存します。ローカルの通信テストでは、CayenChat がこれらのバイトを1つのチャンネル名の一部として扱うことを確認しています。選択した文字コードで表せない文章は、入力欄を消さずに送信を拒否します。サーバーが `UTF8ONLY` を通知した場合は UTF-8 を選んでください。

暗号化接続には **TLS/SSL** を有効にします。ポートを変更していない場合、オンにすると標準ポートが `6667` から `6697` に変わります。証明書は初期状態で検証します。TLS 有効時には、自己署名の Tiarra 証明書などに合わせてサーバーごとの **証明書の検証** をオフにできます。ただしオフにするとサーバーの正当性を確認できず、第三者によるなりすましを検知できません。TLS をオフにすると証明書検証はオンへ戻ります。サーバーパスワードと **SASL PLAIN** には TLS が必要ですが、証明書検証を無効にした場合、認証情報の送信先が正しいサーバーかどうかは保証されません。SASL にはアカウント名とパスワードが必要で、サーバー側が PLAIN に対応した `sasl` を通知する必要があります。

**保存** は再接続せずに設定だけを保存します。**戻る** またはウィンドウの閉じるボタンは設定ウィンドウだけを閉じます。**切断** は現在の接続を切断し、**保存して接続** はフォームの内容で接続し直します。**アプリ起動時に自動接続する** は初期状態でオフです。オンにして保存すると、次回起動時に選択したサーバーへ接続します。保存済み設定から接続を開始できる場合は設定ウィンドウを開かず、設定が不完全なら設定ウィンドウを開きます。自動接続では明示的に保存したパスワードだけを使用します。切断後の自動再接続はまだありません。

設定は OS のユーザー設定ディレクトリ内の `CayenChat/settings.json` に保存されます（macOS の例: `~/Library/Application Support/CayenChat/settings.json`）。バージョン 1～7 の設定は読み込み時に移行されます。証明書検証や起動時自動接続の値が未指定なら、それぞれ有効・無効が初期値になり、保存済みの選択は維持されます。従来の初期背景色 `#ECECEC` はバージョン 8 で白に変わりますが、ほかの保存色は維持します。サーバーと SASL のパスワードは入力欄では伏せられます。サーバーごとの **パスワードを保存する** は初期状態でオフです。オンにする際には、両方のパスワードが設定ファイルへ平文保存されることを確認します。オフにすると保存済みパスワードは直ちに削除されます。オフのまま接続用に入力したパスワードはディスクに書き込みません。接続中のサーバーはチャンネル一覧に状態が表示されます。サーバーを選択すると登録時のメッセージやエラーを確認できます。

接続中や接続失敗後には、選択中のチャンネルまたはサーバー画面に接続診断が自動表示されます。Windows/Linux では **Alt を単独で押して離す**か **F10** でメニューバーが表示され、同じキーまたは Esc で閉じます。タイトルバーのすぐ下にマウスを止めてもメニューバーが現れ、マウスが離れると閉じます。Alt 単独を IME の切り替えに割り当てている場合は、F10 かマウスを使ってください。**表示 → 接続診断を表示** でサーバー画面の診断先頭へ移動でき、**表示 → 接続診断をコピー** で最後の切断理由を含めてコピーできます。macOS では画面上部の標準メニューを使います。macOS のショートカットは `Cmd+Shift+D` / `Cmd+Shift+L`、Windows/Linux では `Ctrl+Shift+D` / `Ctrl+Shift+L` です。`→` は送信キューに入れた IRC コマンド、`←` は受信した IRC 行を表し、DNS、TCP/TLS、登録処理の進行状況と時系列で並びます。診断には発言本文も含まれ、メモリ上には最新 1,000 件を保持するため、共有前に内容を確認してください。サーバー PASS、SASL ペイロード、OPER パスワード、チャンネルキー、既知の NickServ/ChanServ 認証コマンドは伏せられます。IRC 行は文字コードの変換と解析後に表示されるため、TLS やパケットのバイト単位の記録ではありません。ライブラリ内部の保守通信がすべて表示されるわけでもありません。Windows/Linux のメニューはチャット・設定の両ウィンドウで利用でき、矢印キーと Enter でも操作できます。Alt を使う他のショートカットでは開きません。`Ctrl+,` でも別ウィンドウの設定を開けます。

## 外観

設定ウィンドウには **接続** と **外観** のタブがあります。**外観** では、メンバーリスト（初期値は白）、上部チャンネルログ、下部全体ログの背景色を `#RRGGBB` 形式で指定します。行の交互色を有効にすると、メッセージを1行おきに別の色で表示します。上下のログ、ユーザー一覧、チャンネル一覧、入力欄のフォントはインストール済みの候補から選べます。フォント欄へ入力すると候補を絞り込めます。空欄はシステム標準のフォントです。時刻には既定で等幅フォント（macOS: Menlo、Windows: Consolas、Linux: DejaVu Sans Mono）を使います。**保存して適用** は再接続せずに外観を保存・適用します。ニックネーム欄は約12文字分で、それより長い名前は表示上省略されます。

## 言語

**接続**タブの **言語** では、**システムの言語**、**日本語**、**English** を選べます。初期値はシステムの言語です。OS の言語が日本語なら日本語、それ以外は英語を使います。選択すると設定ウィンドウで表示を確認でき、**保存** するとチャット画面とメニューにも再接続なしで反映します。翻訳ファイルは `locales/en.json` と `locales/ja.json` です。配布物に含まれるファイルを実行時に読み、見つからない場合はアプリ内に組み込んだ内容を使います。

## IRC コマンド

入力欄の先頭を `/` にして Enter を押すと、登録完了後に IRC コマンドを送れます。通常の文章は参加済みの選択チャンネルへ `PRIVMSG` で送信します。`Ctrl+Enter` は IRC の `NOTICE` を送ります。次のコマンドはチャンネル名を省略すると選択中のチャンネルを使います。

| 入力例 | 動作 |
| --- | --- |
| `/join #other` | 別のチャンネルへ参加 |
| `/part` または `/part Leaving now` | 選択中のチャンネルから退出 |
| `/topic New topic` | 選択中のチャンネルのトピックを変更。`/topic` だけなら照会 |
| `/mode +o alice` | 選択中のチャンネルのモードを変更 |
| `/kick bob goodbye` | 選択中のチャンネルからユーザーをキック |
| `/invite bob` | 選択中のチャンネルにユーザーを招待 |
| `/names` | 選択中のチャンネルのメンバー一覧を要求 |
| `/me waves` | 選択中のチャンネルへ CTCP ACTION を送信 |
| `/msg :hello everyone` または `/notice :hello everyone` | 選択中のチャンネルへ発言または通知 |
| `/msg bob hello` または `/notice bob hello` | 指定した相手へ直接送信 |
| `/nick newname`、`/whois bob`、`/raw WHO #channel` | その他の IRC コマンドを送信 |

`MSG`、`PRIVMSG`、`NOTICE` では、上記のメッセージ形式の先頭の `:` が選択中のチャンネルを明示します。`/raw` と `/quote` は残りの行を IRC コマンドとして送ります。サーバーの応答はサーバーログに表示します。プライベートメッセージ専用のペインはまだありません。コマンドと発言は、プロトコルの改行や長すぎる行を拒否します。

プラットフォームごとの前提条件は次のとおりです。

| OS | 必要な環境 | 確認状況 |
| --- | --- | --- |
| macOS | macOS SDK とコマンドラインツールを備え、`xcode-select` で選択したフル Xcode。Metal 対応 Mac。 | Apple Silicon / macOS 26.6.2、Rust 1.95.0、Xcode 26.6 でビルド・起動済み。 |
| Windows | 安定版 Rust MSVC ツールチェーン、Visual Studio または C++ デスクトップ開発を含む Build Tools、Windows SDK。必要なら Developer shell から実行。 | Windows 上でのビルド・起動は未確認。 |
| Linux | Rust 1.88 以降、C コンパイラと `pkg-config`、Vulkan 対応 GPU とドライバー。Debian/Ubuntu では `sudo apt install build-essential pkg-config libxcb1-dev libxkbcommon-dev libxkbcommon-x11-dev libwayland-dev libvulkan1 mesa-vulkan-drivers`。[Zed の Linux ビルド要件](https://zed.dev/docs/development/linux)は上流の広い要件を参照できますが、この小さなプロジェクトには不要なものもあります。 | Wayland と X11 の機能は有効。Linux 上でのビルド・起動は未確認。 |

macOS では `icon.png` の画像を使った開発用 `.app` バンドルを任意で作れます。

```sh
sh scripts/bundle-macos.sh
open target/CayenChat.app
```

バンドルは `target/` 内に置かれ、署名、公証、インストールはされません。`icon.png` 由来のアイコンが含まれます。Windows 実行ファイルにも同じ画像から作った `.ico` を埋め込みます。生成済みの `.icns` と `.ico` はコミットされているため、通常のビルドで画像処理ツールは不要です。`icon.png` を変更した場合は、Pillow を導入して `python3 scripts/generate-icons.py` を実行してください。コード変更後は、実行中の CayenChat をすべて Cmd+Q で終了し、`sh scripts/bundle-macos.sh` を再実行してからバンドルを開いてください。`cargo build` だけではバンドル内の実行ファイルは置き換わりません。コード変更時の確認コマンドは次のとおりです。

```sh
cargo fmt --check
cargo clippy --workspace --all-targets --all-features --locked
cargo test --workspace --locked
```

プラットフォームごとの詳細は[開発要件](spec/development.md)を参照してください。

## 画面構成と現在の動作

上側のチャンネルログでは発言本文をドラッグして範囲選択し、`Cmd+C` / `Ctrl+C` でコピーできます。HTTP/HTTPS の URL をダブルクリックするとシステムのブラウザーで開きます。下側の全体ログではシングルクリックによるチャンネル切り替えを優先し、URL は開きません。

左側には上から選択チャンネルのログ、入力欄、他チャンネルの全体ログがあります。右側には上に選択チャンネルのユーザー一覧、下にサーバーとチャンネルの一覧があります。サーバーを選ぶと接続状態とサーバーメッセージが表示され、ユーザー一覧は空になります。全体ログの発言をクリックすると、そのチャンネルへ移動します。全体ログの長いチャンネル名やサーバー名は省略記号で1行に収めます。全体ログは別々のチャンネルで同じ分に受信した場合も、到着順で並べます。上下のログは初回接続時の履歴の一括受信を含め、新しい発言に追従して末尾までスクロールします。ユーザーが上へスクロールすると追従を停止し、末尾へ戻すと再開します。サーバーやチャンネルごとの下書きは終了までメモリに保持します。

他のチャンネルに発言が届くと未読表示が付き、開くと消えます。アクティブなチャンネルの移動は登録・参加状態に従います。未読チャンネルが残っていない場合、未読移動ショートカットは選択を変えません。番号のショートカットは、サーバーツリーに表示されたチャンネル順で選びます。`1` は先頭、`0` は10番目です。存在しない番号なら選択は変わりません。Windows/Linux では **設定 → 外観 → チャンネル番号キー** で修飾キーを Alt または Super に変えられます。デスクトップが Ctrl+数字をワークスペース切り替えに使う場合に選んでください。サーバー番号は `Ctrl+Alt` のままです。

## キーボードショートカット

`Cmd` は macOS の Command、`Opt` は Option を表します。`Ctrl` と `Alt` は Windows/Linux の対応するキーです。Windows/Linux の割り当ては OS 予約の Alt+Tab / Alt+Space を避け、入力欄の単語移動に Ctrl+Left/Right を残しています。

| 操作 | macOS | Windows / Linux |
| --- | --- | --- |
| 選択チャンネルのメンバーからニックネームを補完。繰り返すと候補を切り替え | `Tab` | `Tab` |
| 次の未読チャンネル | `Ctrl+Tab` または `Opt+Space` | `Ctrl+Tab` |
| 前の未読チャンネル | `Ctrl+Shift+Tab` または `Opt+Shift+Space` | `Ctrl+Shift+Tab` |
| 直前に選択したチャンネル | `Opt+Tab` | `Alt+Left` |
| 前後のアクティブなチャンネル | `Cmd+Up/Down`、`Cmd+Opt+Up/Down`、`Cmd+{/}` | `Ctrl+PageUp/PageDown` |
| 前後のチャンネル | `Ctrl+Up/Down` | `Alt+Up/Down` |
| 前後のアクティブなサーバー | `Cmd+Opt+Left/Right` | `Ctrl+Alt+PageUp/PageDown` |
| 前後のサーバー | `Ctrl+Left/Right` | `Alt+PageUp/PageDown` |
| 1～10番目のチャンネル | `Cmd+1..9, 0` | `Ctrl+1..9, 0`（変更可） |
| 1～10番目のサーバー | `Cmd+Ctrl+1..9, 0` | `Ctrl+Alt+1..9, 0` |
| チャンネル発言（`PRIVMSG`）を送信 | `Enter` | `Enter` |
| IRC `NOTICE` を送信 | `Ctrl+Enter` | `Ctrl+Enter` |
| 接続設定を開く | `Cmd+,` | `Ctrl+,` |
| 接続診断を表示・非表示 | `Cmd+Shift+D` | `Ctrl+Shift+D` |
| 接続診断をコピー | `Cmd+Shift+L` | `Ctrl+Shift+L` |
| 上側ログの選択テキストをコピー | `Cmd+C` | `Ctrl+C` |

通常の文章は、選択チャンネルへの参加が完了してから送信されます。スラッシュコマンドは登録完了後のサーバー画面からも入力できます。送信をローカルのキューに入れられたら下書きを消します。切断中または参加処理中の送信は通知を表示し、下書きを残します。入力欄は標準的な OS の編集キー、範囲選択、貼り付け、取り消し・やり直し、IME 入力に対応しています。GPUI 0.2.2 は macOS のユーザー定義 `DefaultKeyBinding.dict` の変更にはまだ従いません。編集キーと重なるアプリのショートカットは上記の割り当てが優先されます。

Windows では IME 変換中に送信とニックネーム補完を抑止します。同梱する GPUI 0.2.2 には、認識できない言語入力キーと IME が処理したキーに関する[上流の修正](https://github.com/zed-industries/zed/pull/41259)の一部を適用しています。半角/全角キーによる MS-IME 切り替えは Windows 11 実機での確認が必要です。
